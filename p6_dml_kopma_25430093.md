### UJ-03 — Pengubahan stok menjadi negatif (`ERROR 4025`)

```sql
USE kopma_093;
SET SESSION sql_safe_updates = 1;
START TRANSACTION;

UPDATE barang
SET stok_barang = -5
WHERE kode_barang = 'MKN-001' AND id_barang > 0;

ROLLBACK;
```
