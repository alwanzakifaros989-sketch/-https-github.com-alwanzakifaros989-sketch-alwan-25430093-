## 3. Kode SQL Pengujian

### UJ-01 — Peminjaman valid oleh anggota aktif

```sql
USE perpus_093;
START TRANSACTION;

INSERT INTO peminjaman (id_anggota, id_petugas, tgl_pinjam, batas_pengembalian)
VALUES (1, 1, '2026-10-18', '2026-10-25');

SELECT * FROM peminjaman WHERE id_peminjaman = LAST_INSERT_ID();

ROLLBACK;
```

## 4. Catatan Utang Desain (Untuk Modul 14)

* **Validasi status keanggotaan saat transaksi (`UJ-10`):** Constraint kolom/tabel pada `peminjaman` tidak memeriksa nilai `status_anggota` pada tabel `anggota` secara otomatis saat `INSERT`, sehingga transaksi oleh anggota berstatus `nonaktif` masih lolos dan akan dicegah melalui logika transaksi di **Modul 14**.
* **Ketersediaan status eksemplar saat dipinjam:** Validasi agar eksemplar yang berstatus dipinjam tidak dapat dipinjamkan kembali secara ganda dan perubahan statusnya berjalan atomik akan ditangani dalam satu blok transaksi (`START TRANSACTION` ... `COMMIT`/`ROLLBACK`) di **Modul 14**.
